# Capability: AI-Assisted Tools

## Status

Research only. These tools should not distract from the core processing and organization
architecture.

## Potential tools

- Blur and focus-quality detection
- Similarity clustering
- Smart culling suggestions
- Auto-keywording
- Face clustering
- Caption generation

## Principles

- Clearly label automated suggestions
- Keep users in control of final decisions
- Prefer local inference when practical
- Explain privacy implications before cloud processing
- Never silently delete or reject media
