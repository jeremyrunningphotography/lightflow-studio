# Capability: Image Processing

## Goal

Offer high-quality batch image preparation without requiring Lightroom or Photoshop for
simple conversion and delivery tasks.

## Planned tools

- RAW conversion
- Resize
- Format conversion
- Web optimization
- Watermarking
- Image contact sheets
- Thumbnail generation

## Requirements

- Preserve EXIF and ICC metadata by default where formats permit
- Support longest-edge, width, height, percentage, and fit-within resizing
- Make sharpening explicit
- Allow quality and bit-depth selection
- Provide sRGB-oriented web presets
- Protect RAW source files
- Use the shared job framework
