# Capability: Workflow Automation

## Goal

Allow users to save and run an entire repeatable media workflow.

## Example

OCF Gallery Export:

1. Select photographer submission folders
2. Verify media readability
3. Normalize names
4. Convert RAW files
5. Resize to gallery dimensions
6. Preserve creator metadata
7. Export a static gallery
8. Generate a QR code
9. Produce a manifest

## Requirements

- Typed step inputs and outputs
- Preflight validation
- Dry run
- Versioned workflow files
- Per-step failure policies
- Pause and cancellation
- Clear intermediate-file policy
- Reusable workflow templates
