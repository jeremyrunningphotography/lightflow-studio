# Architectural Decision Records

Use this directory for decisions that affect more than one feature or are expensive to reverse.

Filename format:

`NNNN-short-decision-title.md`

Each ADR should include:

- Status
- Context
- Decision
- Alternatives considered
- Consequences
- Follow-up work
