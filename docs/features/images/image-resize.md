# Feature: Image Resize

## Goal

Create consistent image derivatives for web, client preview, social, and archive workflows.

## Resize modes

- Width
- Height
- Longest edge
- Fit within box
- Percentage
- No enlargement

## Requirements

- Preserve aspect ratio by default
- Optional crop-to-fill mode
- Configurable resampling
- Optional output sharpening
- Metadata preservation
- ICC profile handling
- Naming templates
- Web-oriented presets
- Before/after dimensions in the plan
