# Feature: Media Verification

## Status

Existing full-decode verification and CSV reporting.

## Goal

Detect unreadable, truncated, or suspicious media before editing, archiving, or deleting
source copies.

## Requirements

- Fast inspection mode
- Full decode mode
- CSV and human-readable report
- File hash option
- Warning severity
- Clear distinction between container warnings and decode errors
- Rerun failed items
- Pipeline compatibility
