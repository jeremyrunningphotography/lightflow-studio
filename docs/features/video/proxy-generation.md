# Feature: Proxy Generation

## Status

Existing capability; expansion planned.

## Goal

Create lightweight editing media with predictable naming and relinking behavior.

## Requirements

- Built-in 1080p preset
- Additional configurable resolutions
- Editing-friendly codec choices
- Preserve source frame rate unless overridden
- Preserve or intentionally remap audio streams
- Deterministic proxy suffix
- Preserve folder structure
- Report source-to-proxy mapping
