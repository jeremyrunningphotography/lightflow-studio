# Feature: Workflow Pipeline Engine

## Goal

Connect stable Lightflow Studio capabilities into saved, repeatable workflows.

## Requirements

- Add, remove, reorder, and configure steps
- Validate input/output compatibility
- Preview the complete job plan
- Save versioned workflow definitions
- Provide built-in templates
- Select stop, skip, or continue behavior on step failure
- Track intermediate outputs
- Support cancellation and later resume
- Generate a consolidated completion report

## Initial candidate steps

- Verify media
- Rewrap
- Apply LUT and convert
- Generate proxy
- Convert RAW
- Resize image
- Rename
- Copy metadata
- Export gallery
- Generate checksum manifest
