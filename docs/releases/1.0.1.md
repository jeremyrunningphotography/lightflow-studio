# Lightflow Studio 1.0.1

Lightflow Studio 1.0.1 fixes explicit Preview regeneration when WPF retained the file handle of an already displayed Preview. Regeneration can now replace that file and refresh the displayed image correctly, including repeated regeneration. If replacement fails, a still-valid prior Preview remains available with the failure warning.

The unnecessary Regenerate Preview confirmation prompt has been removed. Selection and folder scope, progress, and failure feedback remain unchanged.

Normal automatic Preview generation, bounded automatic retry/cooldown behavior, and exclusion of Lightflow-owned cache files remain unchanged. No Catalog or Preview schema change is introduced.

Premiere Companion remains at **1.2.2**. The platform requirements and known limitations in the [1.0.0 release notes](1.0.0.md) continue to apply.
