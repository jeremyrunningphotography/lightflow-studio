# Lightflow Studio 1.0.2

Lightflow Studio 1.0.2 improves Collections and makes normal clean startup substantially faster while retaining safety validation when required.

- Newly created Collections appear immediately and open without restarting Lightflow, including Collections inside nested Collection Sets.
- Collection loading resolves members directly in bounded batches instead of reading the entire Catalog, preserving membership order and unavailable-member behavior. Smart Collections using a Collection as Source benefit from the same improvement.
- Clean, current-schema startup avoids unnecessary full Catalog and Preview checks. Safety validation remains for uncertain shutdowns, migration, restore/recovery, and detected database problems.
- Startup no longer performs unnecessary Preview usage accounting or walks entire derived-cache directory trees for isolated-profile validation.
- When deeper validation is needed, the compact startup splash provides clearer, truthful status information.

No Catalog or Preview schema change is introduced. Premiere Companion remains at **1.2.2**. Platform requirements and known limitations from the [1.0.0 release notes](1.0.0.md) continue to apply.
