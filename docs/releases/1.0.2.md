# Lightflow Studio 1.0.2

Lightflow Studio 1.0.2 fixes two issues with ordinary Collections.

- Newly created Collections now appear immediately and can be opened without restarting Lightflow, including Collections inside nested Collection Sets.
- Opening a Collection now loads its members directly in bounded batches instead of reading the entire Catalog, substantially improving loading in large Catalogs while preserving membership order and unavailable-member behavior.

Smart Collections using a Collection as Source benefit from the same targeted membership loading.

No Catalog or Preview schema change is introduced. Premiere Companion remains at **1.2.2**. Platform requirements and known limitations from the [1.0.0 release notes](1.0.0.md) continue to apply.
