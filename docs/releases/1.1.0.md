# Lightflow Studio 1.1.0 — Windows

Lightflow Studio 1.1 remembers your Export preferences and improves the reliability of selecting, naming and exporting videos and Subclips. This is a Windows-only release; it does not introduce a macOS release.

## New features

- **Export settings persistence and Reset Defaults.** Reusable destination, naming, encoding and LUT choices are remembered across Export sessions and restarts. Reset Defaults restores the profile's defaults while preserving recent folders and its migrated encoding baseline. Current selections, ranges, Jobs and overwrite permission are not reusable preferences.
- **Contextual destinations.** Same as Source resolves each video's own source folder, including mixed-folder Collections. Specific Folder remembers explicit choices and up to ten recent destinations. Create subfolder is independently remembered, supports custom names, and defaults to `Exports`.

## Improvements

- Filename-builder Custom text stays responsive while validation runs in the background. Long text remains readable and editable. Original Name is the sole default naming component, and new Custom values start empty. For saved Subclips, Original Name continues to mean the saved Subclip name.
- Export preparation shows per-file activity and accurate readiness. Existing-file skip and overwrite warnings remain distinct from blocking source-protection and duplicate-output errors.
- Videos without saved Subclips use their own active In/Out marks, or the full source when no marks exist. Saved Subclips retain precedence.

## Bug fixes

- Improved saved Out-point and verified source-EOF handling without weakening range accuracy or source-file protection. Same as Source resolves source codec/container metadata before deciding compatibility; upstream validation failures no longer masquerade as NVENC initialization failures.
- Restored Player keyboard frame navigation after playback-speed selection and neutral Player interaction while preserving dropdown, text and menu ownership.
- Corrected Browser Ctrl+A routing while preserving text editing and Jobs, Subclips and Player selection contexts. Search Enter and successful explicit metadata Apply hand focus back appropriately.
- Folder context commands act on the invoked folder, including an unselected right-clicked folder, with filesystem safety checks preserved.
- Prevented delayed Jobs checkpoint publishers from overwriting newer durable lifecycle state.

## Compatibility and installation

- Windows 10 or Windows 11, 64-bit. Choose `LightflowStudio-1.1.0-win-x64-setup.exe` or `LightflowStudio-1.1.0-win-x64-portable.zip`. The installer requests administrator permission and installs for all users. The portable ZIP avoids installer registration but still uses local user-data locations by default.
- Packages include the .NET runtime and pinned processing/playback dependencies. NVENC H.264/HEVC Export requires a supported NVIDIA GPU and driver; Catalog organization does not.
- Premiere Companion remains **1.2.2**, requiring Premiere Pro 26.5 or later. See [Premiere setup](https://github.com/jeremyrunningphotography/lightflow-studio/blob/release/1.1/docs/premiere-companion.md).
- No Catalog schema migration is added relative to v1.0.2. Keep a supported backup before upgrading. Export preferences use a new versioned file format; reopening updated storage/preferences with an older Lightflow version is unsupported without a preserved pre-upgrade profile.
- Reset Defaults does not delete recent destinations, alter queued Jobs or change source files. Unavailable remembered folders remain visible and require an available writable destination before exporting.
