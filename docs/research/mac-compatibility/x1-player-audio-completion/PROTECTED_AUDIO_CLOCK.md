# Protected causal supplied-sample clock candidate

Scope: causally eligible supplied audio, not measured speaker emission. Raw AudioQueue sample time and IsRunning are observations, never sufficient authority. Callback completion establishes queue buffer reuse/accounting, not physical listening or scanout.

Minimum candidate state: source/session generation, queue epoch, source origin/rate, contiguous submitted output ranges, decoded-source extent, buffer ownership/completion, monotonic raw sample history, protected position and valid/paused/running flags. Generation and epoch invalidate old submissions/callbacks. A raw timestamp discontinuity/regression invalidates the clock.

For a valid playing epoch, eligible output position is bounded by both raw progress and the old contiguous submitted extent, and source position additionally by decoded source extent. Check against OLD supplied extent before any refill: late buffers cannot retroactively authorize time advanced in a supply hole. Position freezes/invalidates at depletion; the video scheduler holds current accepted frame while invalid. No interpolation beyond supply and no extrapolation from host time.

Pause freezes semantic position immediately, without pretending the buffered hardware tail is silent. Resume recreates at the frozen source point with a new epoch, so a counter that advanced during pause cannot cause a jump or silently skip retained source audio. Seek, rate and loop changes flush/dispose/join old queue callbacks, recreate bounded decoder/filter/queue feed and establish a new origin/rate/epoch. Reject stale callbacks; old memory lives until native disposal returns. A production queue may replace recreation with a proven drain/reset protocol later; this proof does not assert recreation is the only possible API strategy.

Native implementation candidate: tools/X1AudioCompletion/audio.hpp. All buffers contain actual decoded/transformed samples, not unbounded synthetic wrapping. Queue callbacks only release slots; control-side service performs bounded decode/refill. This proof uses a mutex and allocating event telemetry; neither is a production real-time callback implementation. Production requires preallocated notification storage, nonblocking callback bookkeeping, worker ownership and bounded service deadlines.

Ten requested invariants are candidate design obligations: supply cap, detectable underrun, stale rejection, seek invalidation, rate source mapping, loop rebase, pause freeze, resume epoch, restart epoch, invalid-clock scheduler hold. CLOCK_PROTOCOL_SIMULATION.json checks supply cap/stale reset/pause/resume under an independent event ledger. It is NOT a native implementation test. Real protected-clock underrun and scheduling qualification remain blocked at AudioQueueStart.

Affine rate mapping is not exact waveform identity. The known atempo content-envelope errors from #378 are preserved. Output sample extent is measured; source origins and trim boundaries are exact for tested1x slices. Later streaming qualification must characterize atempo segment delay/tempo origin uncertainty and avoid declaring physical content alignment from counter arithmetic.
