# Destination for an accepted Console export

No importable file is included yet. Do not use `elite-plus-windows.mapping.json` as a Console import.

After owner acceptance, place the **actual Console export** here, preferably named
`Lightflow-Elite-Plus-Windows-v1` with the extension Console supplies. The
[official desktop workflow](https://www.tourboxtech.com/en/news/import-and-export-presets-in-tourbox.html)
currently documents `.tb`. Do not rename mobile `.tbx` files or fabricate either format.

Before committing a file, record its SHA-256, author, model, firmware, exact Console version,
Lightflow commit, OS/transport, C2 outcome and successful import/relink/retest. Author from a blank
preset with our own mapping; exclude personal macros, file paths and unrelated vendor templates.
Confirm the owner intends redistribution through the official sharing workflow. Inspect provenance
and behavior through Console rather than decoding undocumented internals. Retain the accepted manual
mapping and completed acceptance sheet beside the export. A preset file alone is not acceptance.
